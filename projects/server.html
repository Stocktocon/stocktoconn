Projects - Home Minecraft Server

Return to Projects

A little over a year ago, I set up a minecraft server for my friends. Since then I've successfully managed to keep the server up and running. I'll be using this time to just really shout out Crafty Controller since their software has made managing the minecraft servers extremely simple.

They provide a great web accessible way to get to your server and manage them and lets you skip a lot of steps in setting up servers since it automatically manages a good portion of them.

Managing the server has really been a great experience for me since it gave me a to deal with firewall security with UFW, port forwarding and port security, and a lot of other experiences like watching logs and hardware usage. There's still some optimizations that I need to make to make it run completely smoothly since there's still some stutters on heavy modpacks, but overall it's been great!
